## Development

### (Current) Prerequisites

- [just](https://github.com/casey/just)
- [bun](https://bun.sh)
- [imagemagick](https://imagemagick.org)
- [tailwindcss](https://tailwindcss.com)

### Watching

```bash
just watch
```

### Building

```bash
just build
```
